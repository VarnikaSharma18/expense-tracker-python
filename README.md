# Expense Tracker

A simple Expense Tracker GUI built using Python, Tkinter, and CSV file handling.

# Features
- Add expenses
- Delete expenses
- Store data in CSV files
- Load previous expenses automatically
- Display total expenses
- Category-wise summary

# Technologies Used
- Python
- Tkinter
- CSV
